## T1 — Engine decision: validate properly, then commit ⬅ blocks everything engine-side

Current default is **Unity** (rationale in design doc 06), but the founder wants it
properly investigated ("uitzoeken"), not assumed. Judge against THESE criteria:

1. **Performance for our sim's shape** — hundreds of statistical settlements +
   4,000-year fast-forward + 500–2,000 visible theater agents at Settlement zoom +
   banded zoom Atlas↔Ground over a large terrain. (Unity: DOTS/ECS + Burst.
   UE5: Mass Entity + Nanite/World Partition. Godot: hand-rolled MultiMesh.)
2. **Fit for our game specifically** — illustrated living-map render mode (Atlas band),
   thousands of procedural buildings, region-tinted mood shifts, miracle VFX.
3. **Dual coding: the founder codes too.** Not Claude-only. So: readable C#, gentle
   learning curve, first-class tutorials, a visual editor the founder can live in —
   AND an AI-friendly project shape (text-serialized scenes/prefabs, content
   generated by code/editor scripts) so Claude can drive most of the project too.
4. **Multiplayer support** — must not foreclose the doc-05 ladder: deterministic
   server-authoritative sim, sparse god-command streams, 2–4 players.
   (Unity: NGO/Fishnet/Photon. UE: built-in replication. Either works for our
   shape; determinism discipline matters more than netcode brand.)
5. **Realistic-look asset ecosystem + cost** — character/animation packs,
   scan libraries, licensing (Unity per-seat vs UE 5% royalty >$1M).

**Process (timeboxed, ~2 weeks of evenings):**
- [ ] T1.1 Port the sim core first (T2) so the spike tests something real.
- [ ] T1.2 Unity spike: load SlateSim, render terrain + 300 settlement markers +
      1,000 crowd agents (DOTS), camera with two zoom bands, fast-forward 500 years
      in-editor. Measure FPS, build size, iteration feel, founder comfort.
- [ ] T1.3 Only if Unity disappoints (visual bar or perf): mirror the spike in UE5.
- [ ] T1.4 Write the decision + evidence into design doc 06. After that it is
      SETTLED — no re-litigating without new evidence.

## T3 — Living-world v1: the aliveness contract (in the real game)

Founder-locked scope (design doc 02, "aliveness contract" — 2026-07-15): the world
must do ALL of this to itself, no god input:
- [ ] Wars & raids between cultures/factions (casus belli from values + scarcity +
      religious tension; statistical resolution; watchable as theater later).
- [ ] Clans/factions/dynasties: **Figures v1** — promoted notables (warlords,
      prophets, founders, wyrmslayers) with deeds ledgers and relationships, leading
      named groups.
- [ ] Trade v1: routes with flow volumes; caravans/ships as visible theater;
      prosperity actually travels.
- [ ] Farming/production v1: per-settlement production vectors (grain, fish, ore,
      timber); fields/pastures visible at closer zooms per the Theater Principle.
- [ ] Culture drift & divergence (values vectors; separated populations fork).
- [ ] Migration/refugee flows (already seeded in Phase 0; make it systemic).
- [ ] Chronicle prose + importance + tone for every new event type. No blind spots.
